# Café Nórdico · Tacna

Sitio web de una cafetería ficticia en Tacna, Perú (datos de ejemplo).

Sitio estático: HTML, CSS y JavaScript sin dependencias ni paso de compilación.

- `index.html`: página
- `assets/css/styles.css`: estilos
- `assets/js/main.js`: carta, horario, reservas por WhatsApp, animaciones
- `assets/img/`: fotos (Unsplash)

## Ver en local

```bash
python -m http.server 5500
```

Abre http://localhost:5500

## Despliegue

Importa el repositorio en Vercel con el preset **Other**; no necesita build.
